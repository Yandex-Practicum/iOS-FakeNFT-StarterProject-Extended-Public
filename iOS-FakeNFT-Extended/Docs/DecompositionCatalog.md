## Блок 1 - Верстка экранов

1. Подготовка модуля «Каталог» - 2 ч
- Настройка структуры папок Collection / Models / ViewModel
- Подключение модуля к существующему TabBar/Router
- Заглушки данных для быстрого просмотра верстки

2. Экран «Каталог коллекций» - 7 ч
- Заголовок + подзаголовок
- Верхний правый баттон меню/фильтр
- Список коллекций CollectionView, вертикальный скролл
- Карточка коллекции: коллаж из 3 изображений
- Корректные отступы/радиусы/тени по макету
- Обработка тапа по карточке - переход на экран коллекции

3. Action sheet «Сортировка коллекций» - 3 ч
- Вызов по тапу на иконку в навбаре
- Верстка ActionSheet: заголовок «Сортировка», пункты «По названию», «По количеству NFT», кнопка «Закрыть»
- Полупрозрачный дим-фон над экраном каталога
- Передача выбранного варианта сортировки в ViewModel

4. Экран «Коллекция» - 7 ч
- Верхняя область: большой коллаж из 3 изображений коллекции
- Блок текста: название коллекции, автор, описание в несколько строк
- Сетка NFT
- Карточка NFT
- Изображение с закруглёнными углами
- Иконка «избранное» в правом верхнем углу
- Рейтинг звёздами под картинкой
- Имя NFT
- Цена + иконка статуса/действия
- Обратная навигация к каталогу

Итого: ~19 часов

## Блок 2 - API и интеграция
 
1. Дата-модели и маппинг - 3 ч
- Модели Collection, NFTItem, Author
- DTO для сети и маппинг в доменные модели
- Базовый протокол репозитория для подмены реализаций (mock / prod)

2. API каталога коллекций - 6 ч
- Эндпоинт GET /api/v1/collections?page=&size=&sort=
- Поддержка сортировки по названию и по количеству NFT
- Парсинг ответа, обработка ошибок timeout, server error, empty result
- Инъекция сервиса в ViewModel экрана каталога

3. API данных коллекции и её NFT - 5 ч
- GET /api/v1/collections/{id} - описание коллекции
- GET /api/v1/collections/{id}/items?page=&size= - список NFT
- Поддержка пагинации
- Обновление моделей

4. Интеграция API с UI - 6 ч
- Экран «Каталог»: загрузка списка при открытии, обновление списка после смены сортировки
- Экран «Коллекция»: последовательная загрузка описания + NFT
- Обработка состояний загрузки и ошибок, переиспользуемый state в ViewModel
- Минимальный pull-to-refresh для обоих экранов

ИТОГО: ~20 часов

2. Рейтинги и статусы NFT - 4 ч
