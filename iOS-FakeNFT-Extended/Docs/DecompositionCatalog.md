## Блок 1

1. Подготовка проекта — 1 ч
    - Подготовка общей структуры проекта
2. Экран Профиля (просмотр) — 6 ч
    - Верстка: аватар, имя, описание, сайт
    - Кнопка редактировать
    - Счётчики: “Мои NFT (112)”, “Избранные (11)”
3. Экран «Мои NFT» — 8 ч
    - Верстка карточек (аватар, заголовок, рейтинг, цена)
    - Верстка списка (List/ScrollView)
    - Иконка избранного в правом верхнем углу карточки
    - Action sheet сортировки
    - Пустое состояние («У Вас ещё нет NFT»)
    - ViewModel: сортировка + сохранение выбранного варианта в UserDefaults
4. Экран «Избранные NFT» — 7 ч
    - Сетка 2 столбца + адаптивная высота
    - Карточки NFT как в «Мои NFT», но компактнее
    - Поддержка удаления из избранного
    - Пустой экран («У Вас ещё нет избранных NFT»)
    - Обновление состояния избранного

ИТОГО: ~ 22 часа

## Блок 2

1. API для профиля — 8 ч
    - GET /api/v1/profile/{id}
    - PUT /api/v1/profile/{id} — обновление имени, описания, сайта
    - PUT для изменения аватара (включая "очистить аватар" при удалении)
    - ViewModel: маппинги
    - Обработка ошибок
2. API для NFT — 8 ч
    - GET /api/v1/nft?page=&size=
    - GET /api/v1/nft/{id}
    - Фильтрация NFT по списку избранного
    - Маппинг моделей
3. Интеграция API с экранами — 10 ч
    - Экран Профиля
    - Загрузка данных
    - Экран «Мои NFT»
    - Экран «Избранные NFT»
    - Обновление избранного

ИТОГО: ~26 часов

## Блок 3

1. Экран «Редактирование профиля» — верстка — 7 ч
    - Поле Имя
    - Поле Описание
    - Поле Сайт
    - Кнопка «Сохранить» снизу (disable если нет изменений)
    - Обработка клавиатуры + скролл
2. Логика редактирования — 6 ч
    - Отслеживание изменений
    - Валидация URL сайта
    - Подготовка тела запроса
    - Показывать/скрывать лоадер при сохранении
    - Алерт при попытке выйти без сохранения
3. Работа с фото — 6 ч
    - Action sheet «Изменить фото/Удалить фото/Отмена»
    - Алерт ввода ссылки на фото (как по макету)
    - Проверка валидного URL
    - Отправка обновлённого URL в профиль
    - Очистка фото ("Удалить фото")
4. Состояния и ошибки — 4 ч
    - Показ/скрытие лоадеров
    - Ошибка сети
    - Ошибка сохранения профиля
    - Ошибка загрузки аватара

ИТОГО: ~23 часов
