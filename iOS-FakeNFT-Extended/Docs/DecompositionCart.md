# Блок 1 — UI корзины 

## 1. Экран «Корзина» (CartView) — 7 ч
- Базовая структура экрана: список NFT, верхний бар, нижняя панель.
- Верстка списка NFT (List/ScrollView): отступы, фон, адаптивность.
- Пустое состояние: экран «Корзина пуста».
- Кнопка сортировки в navigation bar.

## 2. Ячейка NFT в корзине (CartNFTCellView) — 7 ч
- Изображение NFT, рейтинг, название, цена.
- Кнопка удаления (иконка справа); выравнивание элементов.
- Адаптивная высота карточки, корректные отступы.
- Обработка нажатия → вызов подтверждения удаления.

## 3. Экран сортировки (CartFilterView) — 7 ч
- Список вариантов сортировки: цена, рейтинг, название.
- Radio-выбор, выделение выбранного пункта.
- Кнопка подтверждения; обновление состояния сортировки.
- Корректное отображение выбранной сортировки при повторном открытии.

## 4. Экран выбора валюты (CurrencySelectionView) — 8 ч
- Верстка списка валют (иконка, название, курс).
- Ячейка CurrencyCellView + отображение selected-состояния.
- Кнопка подтверждения выбора валюты.
- Состояния: загрузка, ошибка, отсутствуют валюты.

**Итого: 29 ч**

# Блок 2 — Локальная логика, сортировка, мок-данные

## 1. Навигация и модели — 8 ч
- Настройка переходов: сортировка, выбор валюты, подтверждение удаления.
- Актуализация моделей NFT, CartItem, Currency.
- Подготовка мок-данных для корзины и валют.
- Отображение мок-данных на экране корзины.

## 2. Локальная логика корзины — 10 ч
- Удаление NFT локально + обновление UI.
- Пересчёт суммы и количества NFT.
- Скрытие/показ нижней панели в зависимости от содержимого.
- Показ EmptyState при пустой корзине.

## 3. Логика сортировки — 7 ч
- Реализация сортировок: по цене, рейтингу, названию.
- Применение сортировки к текущему списку.
- Сохранение выбора сортировки в @AppStorage.
- Автоприменение выбора при открытии корзины.

## 4. Подготовка к API — 5 ч
- Приведение ViewModels к структуре API.
- Интерфейсы для загрузки корзины, валют, оплаты.
- Обработка состояний: loading, error, empty.
- Интеграционные тесты на мок-слой.

**Итого: 30 ч**

# Блок 3 — Интеграция API и логика оплаты

## 1. Загрузка корзины и валют — 10 ч
- Интеграция GET /cart (загрузка списка).
- Интеграция DELETE /cart/{id} (удаление NFT).
- Интеграция GET /currency (список валют).
- Обработка ошибок, лоадеры, обновление UI.

## 2. Логика оплаты — 12 ч
- Интеграция POST /payment с передачей выбранных NFT.
- Обработка success/failed ответов API.
- Переходы на PaymentSuccessView / PaymentErrorView.
- Очистка корзины после успешной покупки.

## 3. Обновление профиля (после покупки) — 6 ч
- Добавление купленных NFT в профиль.
- Обновление локального состояния приложения.
- Перезагрузка данных после покупки.

## 4. Дополнительные функции — 4 ч
- WebView для пользовательского соглашения.
- Индикаторы загрузки на всех экранах.
- Единая система ошибок API.

**Итого: 32 ч**
